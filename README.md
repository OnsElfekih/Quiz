# Interactive Quiz

Interactive Quiz is a web application that allows users to participate in quizzes, and create, modify, or delete their own quizzes.

## Features

- User authentication for secure login and registration
- Quiz management: create, edit, and delete quizzes
- Question management: add, edit, and remove quiz questions
- Answer handling: set correct answers for each question
- Quiz participation: take quizzes and submit answers
- Score tracking: view individual quiz scores
- Account management: update personal account information

## Technologies Used

- **Frontend:**  
  React, HTML5, CSS3

- **Backend:**  
  Node.js, MongoDB, JWT (JSON Web Token)

- **Version Control:**  
  Git
